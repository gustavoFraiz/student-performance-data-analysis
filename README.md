# Student Performance Data Analysis

Exploratory data analysis and machine-learning study of the UCI **Student Performance** dataset.

The project investigates demographic, social and academic variables and their relationship with student outcomes. It includes descriptive statistics, univariate and multivariate analysis, visualization and predictive modeling.

Examples of questions explored include:

- relationship between alcohol consumption and absences;
- rural vs. urban residence and final grades;
- family structure and absences;
- study time and grades;
- absences and final academic performance.

The cleaned source also evaluates three classifiers for a binary approval task using 5-fold cross-validation: Logistic Regression, Random Forest and SVM.
